# Lv0 進捗: 安全ルール

- [x] 実データを使わない理由を説明できる
- [x] `.env` やAPIキーを扱わない理由を説明できる
- [x] localhostと本番環境の違いをざっくり説明できる
- [x] 止まるべき条件を3つ言える

メモ:メモ:

## 実データを使わない理由
- 個人情報漏洩の危険があるから
- 練習でミスっても実害ゼロにしたいから

## .env / APIキーを扱わない理由
- 機密情報が漏れるから
- APIキーは外部サービスの鍵、漏れたら不正利用されるから

## localhostと本番環境の違い
- localhost = 自分のPCの中の練習場（下書き）。自分しか見えない、何度失敗してもOK
- 本番環境 = インターネット上の本舞台。誰でもアクセスできる、失敗したらクレーム
- mainブランチと本番環境は別物（mainはコードのバージョン、本番は動かす場所）

## 止まるべき条件3つ
- 課題以外に変えるところが見つかった
- 本番環境をいじりそうになった
- なんで今こうなっているのか説明できない

## 開発の流れ
- 1. practice/xxx ブランチで開発（コードを書き換える）
        ↓
- 2. localhost で動かして「ちゃんと動くか」確認
        ↓
- 3. PR作成 → CIテスト → レビュー → main にマージ
        ↓
- 4. main から本番にデプロイ
        ↓
- 5. お客さんが本番環境で新機能を使えるようになる
→ 「ブランチで開発、localhostで確認、本番にデプロイ」 が王道。
