# 私の家計簿アプリ要件

## アプリ名

3カテゴリ家計簿

## 使う人

自分。パソコンで毎日、支出を入力する。

## 解決したい悩み

食費・生活費・子ども費が混ざって見えにくい。月末や年末に「いくら使ったか」「予算と比べてどうか」をすぐ確認したい。

## 管理したいカテゴリ

| カテゴリ | 含める支出の例 |
| --- | --- |
| 食費 | スーパー、外食、お弁当 |
| 生活費 | 光熱費、日用品、交通費、衣服 |
| 子ども費 | 習い事、学用品、子どもの衣服・医療 |

カテゴリはこの3つに固定する。最初は細かいサブカテゴリは作らない。

## 知りたいこと

1. **今月の支出合計** — 全体合計と、食費・生活費・子ども費それぞれの合計
2. **今月の予算残額** — カテゴリごとの予算から支出を引いた残り（予算 − 支出）。超過した場合はマイナス表示でわかるようにする
3. **年間支出合計** — 今年1月から今月までの累計。全体合計に加え、食費・生活費・子ども費のカテゴリ別にも表示する

## 入力のルール

- 1件の支出には、**日付・内容（メモ）・金額・カテゴリ** を付ける
- 金額は円単位の整数
- 日付は支出が発生した日（デフォルトは入力日）
- 毎日パソコンで入力する。スマホ対応は今回の対象外

## 予算のルール

- カテゴリごとに月予算を設定できる（食費・生活費・子ども費それぞれ）
- 月を切り替えると、その月の予算を設定・表示できる
- **今月の予算残額** = そのカテゴリの予算 − そのカテゴリの支出合計
- 全体の予算残額は、3カテゴリの予算残額の合計として表示してよい

## 最初に必ずほしい機能

- 支出を追加できる（日付・内容・金額・カテゴリ）
- 支出一覧を見られる
- 月を選ぶと、その月の支出だけ表示できる
- 表示中の月について、**今月の支出合計**（全体＋カテゴリ別）が見える
- **カテゴリごとに月予算を設定**できる（食費・生活費・子ども費それぞれ）
- **今月の予算残額**を表示する（予算 − 支出。カテゴリ別と全体）
- **年間支出合計**を表示する（今年の累計。全体＋カテゴリ別）

## あるとうれしい機能

- ブラウザを閉じてもデータが残る（localStorage など）
- 入力ミスを直せる（編集・削除）
- 使いすぎがひと目でわかる表示（予算超過時の色分けなど）
- CSVでエクスポートできる

## 今回やらないこと

- 銀行・クレジットカード連携
- ログイン・複数ユーザー
- スマホ専用UI・PWA
- 本番公開・外部サーバーへのデータ送信
- 収入管理・貯金目標・投資管理
- グラフ・レポートの高度な分析

## 完成条件

- localhost で支出を追加できる
- 食費・生活費・子ども費の3カテゴリで分類できる
- 月を切り替えると一覧と合計が変わる
- カテゴリごとに月予算を設定できる
- 今月の支出合計・予算残額（予算 − 支出）・年間支出合計（カテゴリ別含む）が画面で確認できる
- `npm run lint`、`npm test`、`npm run build` が通る
- PRで差分と検証結果を説明できる

## 技術構成

推奨: **Next.js**（このリポジトリの既存構成に合わせる）

## Issue への分解の目安

小さく進めるため、次の順で Issue を切ることを想定する。

1. 支出入力フォーム（3カテゴリ対応）
2. 支出一覧表示
3. 月別フィルタと月合計
4. カテゴリ別合計
5. カテゴリごとの月予算設定（食費・生活費・子ども費）
6. 今月の予算残額表示（予算 − 支出）
7. 年間支出合計（全体＋カテゴリ別）
8. （任意）localStorage 保存、編集・削除、CSV出力
